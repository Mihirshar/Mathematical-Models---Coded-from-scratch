# Sequence Models

Models designed to process sequential text data with temporal dependencies.

## Models

- **RNNs**: Recurrent Neural Networks for sequences
- **LSTMs**: Long Short-Term Memory networks
- **GRUs**: Gated Recurrent Units
- **Transformers**: Attention-based models (modern standard)

## Why Sequence Models?

- Text is inherently sequential
- Word order matters
- Context from previous words important
- Need to model dependencies

## Applications

- Language modeling
- Machine translation
- Text generation
- Sentiment analysis
- Named entity recognition

## Modern Approach

- Transformers have largely replaced RNNs
- Attention mechanisms
- Parallel processing
- Better long-range dependencies
