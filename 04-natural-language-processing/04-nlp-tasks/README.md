# NLP Tasks

Common natural language processing tasks and their applications.

## Classification Tasks

- **Sentiment Analysis**: Classify text sentiment (positive/negative)
- **Text Classification**: Categorize documents
- **Spam Detection**: Identify spam emails/messages
- **Topic Modeling**: Discover topics in documents

## Generation Tasks

- **Text Generation**: Generate new text
- **Machine Translation**: Translate between languages
- **Summarization**: Create summaries of long texts
- **Question Answering**: Answer questions from context

## Information Extraction

- **Named Entity Recognition (NER)**: Extract entities (names, locations)
- **Relation Extraction**: Find relationships between entities
- **Keyphrase Extraction**: Extract important phrases

## Other Tasks

- **Part-of-Speech Tagging**: Label word types
- **Dependency Parsing**: Analyze sentence structure
- **Coreference Resolution**: Link pronouns to entities
