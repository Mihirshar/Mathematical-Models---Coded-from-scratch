## Learning Path

1. **Foundations** - Python, Math, NumPy/Pandas
2. **Classical ML** - Supervised/Unsupervised learning
3. **Deep Learning** - Neural networks, CNNs, RNNs
4. **NLP** - Text processing and sequence models
5. **Generative AI** - Transformers, LLMs, Fine-tuning
6. **MLOps** - Deployment and production systems

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Mihirshar/Mathematical-Models---Coded-from-scratch.git
cd Mathematical-Models---Coded-from-scratch

# Install dependencies
pip install -r requirements/base.txt

# Run tests
pytest tests/
```
