# Generative AI

Generative AI creates new content including text, images, code, and more using large language models.

## Contents

- **01-foundations/** - Core concepts: generative vs discriminative, likelihood, autoregressive models
- **02-transformers/** - Transformer architecture: attention, multi-head attention, positional encoding
- **03-large-language-models/** - LLMs: GPT, BERT, LLaMA, inference pipelines
- **04-prompt-engineering/** - Techniques for effective prompting: zero-shot, few-shot, chain-of-thought
- **05-fine-tuning/** - Adapting models: full fine-tuning, PEFT/LoRA, instruction tuning
- **06-genai-applications/** - Real-world applications: RAG, agents, chatbots, embeddings

## What is Generative AI?

AI systems that generate new content rather than just classifying or predicting:
- Text generation
- Image generation
- Code generation
- Music and audio generation

## Key Technologies

- **Transformers**: Architecture powering modern LLMs
- **Large Language Models**: Models with billions of parameters
- **Prompt Engineering**: Crafting effective inputs
- **Fine-tuning**: Adapting models to specific tasks

## Applications

- Content creation
- Code assistance
- Question answering
- Conversational AI
- Data augmentation

## Prerequisites

- Deep learning fundamentals
- Understanding of transformers
- NLP basics
- Python and PyTorch/TensorFlow
