# Cloud Platform Setup

This directory contains setup guides for various cloud platforms used in ML/AI development and deployment.

## Platforms

- **gcp/** - Google Cloud Platform setup
- **aws/** - Amazon Web Services setup
- **azure/** - Microsoft Azure setup

## Use Cases

- Running training jobs on cloud GPUs
- Deploying models to production
- Using cloud-based ML services
- Managing cloud storage for datasets

## Getting Started

Choose your preferred cloud platform and follow the respective setup guide.
