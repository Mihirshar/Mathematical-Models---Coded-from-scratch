# Environment Setup

This directory contains guides and configurations for setting up your development environment for AI/ML and Generative AI work.

## Contents

- **local/** - Local Python environment setup (virtual environments, Python installation)
- **gpu/** - GPU/CUDA setup for accelerated computing
- **docker/** - Docker containerization for consistent environments
- **cloud/** - Cloud platform setups (GCP, AWS, Azure)

## Getting Started

1. Start with `local/python-setup.md` for basic Python installation
2. Set up a virtual environment using `local/virtualenv.md`
3. For GPU acceleration, follow `gpu/cuda-setup.md`
4. Use Docker for containerized development (see `docker/`)

## Prerequisites

- Python 3.9 or higher
- pip package manager
- (Optional) NVIDIA GPU with CUDA support for GPU acceleration
