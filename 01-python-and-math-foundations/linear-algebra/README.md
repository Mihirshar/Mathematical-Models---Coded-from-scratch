# Linear Algebra

Linear algebra is fundamental to understanding machine learning algorithms and neural networks.

## Contents

- **vectors/** - Vector operations, dot products, norms
- **matrices/** - Matrix operations, multiplication, transpose, inverse
- **eigen-decomposition/** - Eigenvalues, eigenvectors, and their applications
- **svd/** - Singular Value Decomposition for dimensionality reduction
- **ml-applications/** - How linear algebra is used in ML algorithms

## Key Concepts

- **Vectors**: Represent features and data points
- **Matrices**: Represent datasets and transformations
- **Eigenvalues/Eigenvectors**: Used in PCA and other dimensionality reduction techniques
- **SVD**: Foundation for many ML algorithms including PCA and matrix factorization

## ML Applications

- Principal Component Analysis (PCA)
- Linear regression
- Neural network weight matrices
- Image processing and computer vision
- Natural language processing (word embeddings)

## Prerequisites

- Basic algebra
- Understanding of coordinate systems
