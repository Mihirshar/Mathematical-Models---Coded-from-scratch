# Calculus

Calculus is essential for understanding optimization, gradients, and how neural networks learn.

## Contents

- **derivatives/** - Understanding derivatives and rates of change
- **partial-derivatives/** - Partial derivatives for multivariable functions
- **gradients/** - Gradient vectors and gradient descent
- **backprop-math/** - Mathematical foundations of backpropagation algorithm

## Key Concepts

- **Derivatives**: Measure rate of change, used in optimization
- **Partial Derivatives**: Derivatives with respect to one variable while others are constant
- **Gradients**: Vector of partial derivatives, points in direction of steepest ascent
- **Gradient Descent**: Optimization algorithm using gradients to find minima

## ML Applications

- **Gradient Descent**: Core optimization algorithm for training ML models
- **Backpropagation**: How neural networks learn by propagating gradients backward
- **Loss Function Optimization**: Minimizing error in predictions
- **Hyperparameter Tuning**: Finding optimal model parameters

## Why It Matters

Understanding calculus helps you:
- Understand how models learn
- Debug training issues
- Implement optimization algorithms
- Understand regularization techniques
