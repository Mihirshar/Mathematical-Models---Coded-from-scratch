# Statistics

Statistics provides tools for analyzing data, making inferences, and evaluating ML models.

## Contents

- **descriptive/** - Descriptive statistics: mean, median, mode, standard deviation
- **inferential/** - Inferential statistics: sampling, estimation, confidence intervals
- **hypothesis-testing/** - Hypothesis testing: t-tests, chi-square tests, ANOVA
- **confidence-intervals/** - Confidence intervals and margin of error

## Key Concepts

- **Descriptive Statistics**: Summarizing and describing data
- **Inferential Statistics**: Drawing conclusions about populations from samples
- **Hypothesis Testing**: Testing claims about data
- **Confidence Intervals**: Ranges of values with specified confidence levels

## ML Applications

- **Model Evaluation**: Statistical metrics for model performance
- **Feature Selection**: Identifying significant features
- **A/B Testing**: Comparing model versions
- **Cross-Validation**: Statistical validation techniques
- **Error Analysis**: Understanding model errors statistically

## Why It Matters

Statistics helps you:
- Evaluate model performance rigorously
- Make data-driven decisions
- Understand significance of results
- Avoid overfitting and validate models properly
