# Probability

Probability theory provides the foundation for understanding uncertainty, randomness, and statistical inference in machine learning.

## Contents

- **random-variables/** - Discrete and continuous random variables
- **distributions/** - Common probability distributions (normal, binomial, Poisson, etc.)
- **bayesian-thinking/** - Bayesian probability and inference
- **expectation-variance/** - Expected values, variance, and moments

## Key Concepts

- **Random Variables**: Variables whose values depend on chance
- **Probability Distributions**: Functions describing probabilities of different outcomes
- **Bayesian Inference**: Updating beliefs based on evidence
- **Expectation**: Average value of a random variable
- **Variance**: Measure of spread or uncertainty

## ML Applications

- **Naive Bayes**: Classification using probability
- **Gaussian Processes**: Probabilistic ML models
- **Uncertainty Quantification**: Measuring model confidence
- **A/B Testing**: Statistical hypothesis testing
- **Bayesian Neural Networks**: Probabilistic deep learning

## Why It Matters

Probability helps you:
- Understand model uncertainty
- Make informed decisions with incomplete information
- Evaluate model performance statistically
- Understand Bayesian approaches to ML
