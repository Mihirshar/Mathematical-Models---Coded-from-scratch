# Python and Mathematical Foundations

This directory covers the essential Python programming skills and mathematical foundations required for machine learning and AI.

## Contents

- **python/** - Python programming fundamentals (basics, OOP, functional programming, performance)
- **numpy-pandas/** - Data manipulation with NumPy and Pandas
- **linear-algebra/** - Vectors, matrices, SVD, eigen decomposition, and ML applications
- **calculus/** - Derivatives, gradients, partial derivatives, and backpropagation mathematics
- **probability/** - Random variables, distributions, Bayesian thinking, expectation, and variance
- **statistics/** - Descriptive statistics, inferential statistics, hypothesis testing, confidence intervals

## Learning Path

1. Start with Python basics if you're new to programming
2. Master NumPy and Pandas for data manipulation
3. Study linear algebra - fundamental for understanding ML algorithms
4. Learn calculus concepts, especially gradients for optimization
5. Understand probability and statistics for data analysis and model evaluation

## Prerequisites

- Basic programming knowledge (helpful but not required)
- High school mathematics
