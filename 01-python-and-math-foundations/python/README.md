# Python Programming

This directory covers Python programming fundamentals essential for ML/AI development.

## Contents

- **basics/** - Python basics: syntax, data types, control flow, functions
- **oop/** - Object-oriented programming: classes, inheritance, polymorphism
- **functional-programming/** - Functional programming concepts: lambdas, map, filter, reduce
- **performance-tips/** - Performance optimization: profiling, vectorization, efficient coding

## Learning Order

1. Start with `basics/` to learn Python fundamentals
2. Move to `oop/` for object-oriented concepts
3. Explore `functional-programming/` for functional paradigms
4. Study `performance-tips/` for writing efficient code

## Why Python for ML/AI?

- Extensive ML libraries (scikit-learn, PyTorch, TensorFlow)
- Easy to read and write
- Strong community support
- Excellent data science ecosystem
