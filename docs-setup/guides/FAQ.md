# Frequently Asked Questions (FAQ)

## General Questions

### What is this repository?
A comprehensive learning resource for AI, ML, and Generative AI from foundations to advanced topics.

### Who is this for?
- Beginners starting their AI/ML journey
- Intermediate practitioners deepening their understanding
- Anyone preparing for ML interviews
- Students learning algorithms from first principles

### Do I need prior experience?
Basic programming knowledge is helpful but not required. We start from fundamentals.

## Technical Questions

### What Python version is required?
Python 3.9 or higher is required.

### Can I use this on Windows/Mac/Linux?
Yes! The repository is cross-platform compatible.

### Do I need a GPU?
No, but GPU acceleration is recommended for deep learning sections.

### How do I install dependencies?
```bash
pip install -r requirements/base.txt
```

## Learning Questions

### What order should I follow?
Follow the numbered directories: 01-foundations → 02-classical-ml → ... → 08-projects

### How long does it take to complete?
The full curriculum is designed for ~26 weeks of study.

### Are there video tutorials?
Check the resources/ directory for curated video links.
