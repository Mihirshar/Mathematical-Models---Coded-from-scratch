# Mathematical Models - Coded from Scratch

Welcome to the **Mathematical Models - Coded from Scratch** repository! This repository serves as a comprehensive collection of mathematical models and AI techniques implemented entirely from scratch. The goal is to provide a foundational understanding of key concepts through hands-on code while systematically advancing toward cutting-edge topics.

## Repository Structure

### 00_infrastructure_ops
This module deals with the foundational infrastructure for the project, including any computational setup and operational code.

### 01_mathematics_foundations
Exploration of core mathematical foundations essential for understanding models and algorithms.

### 02_classical_ml_engines
Implementation of classical machine learning algorithms from scratch, such as linear regression, decision trees, clustering, etc.

### 03_neural_architecture_lab
Code for building and testing different neural network architectures, ranging from basic feedforward networks to complex architectures.

### 04_nlp_and_llms
Focuses on natural language processing (NLP) and large language models (LLMs), with implementations of key techniques and algorithms.

### 05_slm_and_domain_ai
Specialized learning methods and domain-specific AI projects.

### 06_agentic_systems
Investigations and implementations around agentic systems and autonomous technologies.

### 07_capstone_projects
This section features larger, integrative projects that tie together various implemented approaches.

### 08_benchmarking_and_eval
Evaluation metrics and benchmarks to test and compare the performance of implemented algorithms.

## Features
- Build mathematical understanding of algorithms step-by-step.
- Gain insight into key AI and ML concepts.
- Explore hands-on coding implementations from basic to advanced.

## Usage
1. Clone the repository:
   ```sh
   git clone https://github.com/Mihirshar/Mathematical-Models---Coded-from-scratch.git
   cd Mathematical-Models---Coded-from-scratch
   ```

2. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```

3. Navigate to the relevant folders to explore and execute the code.
