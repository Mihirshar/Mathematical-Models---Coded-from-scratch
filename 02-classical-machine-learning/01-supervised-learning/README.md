# Supervised Learning

Supervised learning algorithms learn from labeled training data to make predictions on new, unseen data.

## Contents

- **regression/** - Predicting continuous values (prices, temperatures, etc.)
- **classification/** - Predicting discrete categories (spam/not spam, image classes, etc.)

## Regression

Predicts continuous numerical values:
- Linear regression
- Polynomial regression
- Ridge, Lasso, Elastic Net regularization

## Classification

Predicts discrete categories:
- Logistic regression
- K-Nearest Neighbors (KNN)
- Naive Bayes
- Support Vector Machines (SVM)
- Decision Trees

## Key Concepts

- **Training**: Learning patterns from labeled data
- **Testing**: Evaluating performance on unseen data
- **Overfitting**: Model memorizes training data but fails on new data
- **Underfitting**: Model too simple to capture patterns

## Use Cases

- **Regression**: House price prediction, stock forecasting, temperature prediction
- **Classification**: Email spam detection, image recognition, medical diagnosis
