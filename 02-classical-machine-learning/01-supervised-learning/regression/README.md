# Regression

Regression algorithms predict continuous numerical values from input features.

## Contents

- **linear-regression/** - Simple and multiple linear regression
- **polynomial-regression/** - Non-linear relationships using polynomial features
- **ridge-lasso-elasticnet/** - Regularization techniques to prevent overfitting
- **regression-case-studies/** - Real-world regression projects

## Linear Regression

The simplest regression algorithm:
- Assumes linear relationship between features and target
- Uses least squares to find best fit line
- Fast and interpretable

## Polynomial Regression

Extends linear regression to capture non-linear patterns:
- Uses polynomial features
- Can model curves and complex relationships
- Prone to overfitting with high degrees

## Regularization

Techniques to prevent overfitting:
- **Ridge (L2)**: Penalizes large coefficients
- **Lasso (L1)**: Can zero out coefficients (feature selection)
- **Elastic Net**: Combines Ridge and Lasso

## Evaluation Metrics

- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R-squared (coefficient of determination)
