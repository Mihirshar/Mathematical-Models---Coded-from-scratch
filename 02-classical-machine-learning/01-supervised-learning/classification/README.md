## Algorithms Overview

### Logistic Regression
- Probabilistic classifier
- Outputs probability of each class
- Works well for binary and multiclass problems

### K-Nearest Neighbors (KNN)
- Instance-based learning
- Classifies based on k nearest neighbors
- Simple but can be slow for large datasets

### Naive Bayes
- Based on Bayes' theorem
- Assumes feature independence
- Fast and works well with text data

### Support Vector Machines (SVM)
- Finds optimal decision boundary
- Works well with high-dimensional data
- Can handle non-linear boundaries with kernels

### Decision Trees
- Tree-structured model
- Highly interpretable
- Can overfit without regularization

## Evaluation Metrics

- Accuracy
- Precision and Recall
- F1-Score
