# Unsupervised Learning

Unsupervised learning finds hidden patterns in data without labeled examples.

## Contents

- **clustering/** - Grouping similar data points together
- **dimensionality-reduction/** - Reducing number of features while preserving information
- **anomaly-detection/** - Identifying unusual or outlier data points

## Clustering

Groups data into clusters based on similarity:
- **K-means**: Partition data into k clusters
- **Hierarchical**: Builds tree of clusters
- **DBSCAN**: Density-based clustering, finds arbitrary shapes

## Dimensionality Reduction

Reduces feature space while preserving important information:
- **PCA**: Principal Component Analysis - linear dimensionality reduction
- **LDA**: Linear Discriminant Analysis - supervised dimensionality reduction
- **t-SNE**: Non-linear visualization technique
- **UMAP**: Modern non-linear dimensionality reduction

## Anomaly Detection

Identifies outliers and unusual patterns:
- **Isolation Forest**: Tree-based anomaly detection
- **One-Class SVM**: Support vector machine for anomaly detection

## Use Cases

- Customer segmentation
- Feature engineering
- Data visualization
- Fraud detection
- Data preprocessing

## When to Use

- No labeled data available
- Exploratory data analysis
- Feature reduction needed
- Finding hidden patterns
