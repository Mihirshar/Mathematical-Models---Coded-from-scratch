# Classical Machine Learning

This directory covers traditional machine learning algorithms and techniques, from supervised to unsupervised learning.

## Contents

- **01-supervised-learning/** - Learning from labeled data (regression and classification)
- **02-ensemble-learning/** - Combining multiple models for better performance
- **03-unsupervised-learning/** - Learning patterns from unlabeled data
- **04-model-evaluation/** - Techniques for evaluating and selecting models

## Learning Path

1. Start with supervised learning (regression and classification)
2. Learn ensemble methods to improve model performance
3. Explore unsupervised learning for pattern discovery
4. Master model evaluation techniques

## Prerequisites

- Python and NumPy/Pandas
- Basic understanding of linear algebra and statistics
- Familiarity with scikit-learn library
