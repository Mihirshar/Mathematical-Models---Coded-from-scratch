# Assets

Visual resources for documentation and presentations.

## Structure

- `images/` - Screenshots, photos, and general images
- `diagrams/` - Architecture diagrams, flowcharts, and technical diagrams
- `presentations/` - Slide decks and presentation materials

## Usage

### In Markdown
```markdown
![Description](../assets/images/example.png)
```

### In Notebooks
```python
from IPython.display import Image
Image('assets/images/example.png')
```

## Tools

Recommended tools for creating diagrams:
- **draw.io** - Free diagramming tool
- **Excalidraw** - Hand-drawn style diagrams
- **Mermaid** - Text-based diagrams
- **PlantUML** - UML diagrams from text

## File Naming

Use descriptive names:
- `neural-network-architecture.png`
- `transformer-attention-mechanism.svg`
- `training-pipeline-flowchart.pdf`
