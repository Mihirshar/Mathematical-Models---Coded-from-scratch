# Notebooks

Interactive Jupyter notebooks for learning and experimentation.

## Structure

- `01-foundations/` - Python, Math, NumPy/Pandas notebooks
- `02-classical-ml/` - Classical ML algorithm notebooks
- `03-deep-learning/` - Deep learning tutorials
- `04-nlp/` - NLP and text processing notebooks
- `05-genai/` - Generative AI and LLM notebooks
- `06-rl/` - Reinforcement learning notebooks
- `07-mlops/` - MLOps and deployment notebooks
- `exploratory/` - Experimental and exploratory analysis
- `tutorials/` - Step-by-step tutorial notebooks

## Naming Convention

Use the following format for notebook names:
```
<number>-<descriptive-name>.ipynb
```

Examples:
- `01-linear-regression-from-scratch.ipynb`
- `02-neural-network-basics.ipynb`
- `03-transformer-attention.ipynb`

## Running Notebooks

```bash
# Start Jupyter Lab
jupyter lab

# Or Jupyter Notebook
jupyter notebook
```

## Best Practices

1. Clear all outputs before committing
2. Keep notebooks focused on a single topic
3. Include markdown explanations
4. Add visualizations where helpful
5. Test code cells run in order
