# Reinforcement Learning

Learning through interaction with an environment to maximize cumulative rewards.

## Contents

- **01-rl-basics/** - Fundamentals: agents, environments, rewards, policies
- **02-classical-rl/** - Traditional RL algorithms (Q-learning, SARSA)
- **03-deep-rl/** - Deep reinforcement learning (DQN, Policy Gradients, PPO)
- **04-rl-applications/** - Real-world applications and case studies

## What is Reinforcement Learning?

- Agent learns by trial and error
- Receives rewards/penalties
- Learns optimal policy
- Different from supervised learning

## Key Components

- **Agent**: The learner/decision maker
- **Environment**: The world the agent interacts with
- **State**: Current situation
- **Action**: What the agent does
- **Reward**: Feedback signal
- **Policy**: Strategy for choosing actions

## Applications

- Game playing (Chess, Go, Atari)
- Robotics and control
- Autonomous vehicles
- Recommendation systems
- Resource allocation

## Challenges

- Exploration vs exploitation
- Sparse rewards
- Sample efficiency
- Stability during training

## Prerequisites

- Probability and statistics
- Basic machine learning
- Understanding of optimization
- Python programming
